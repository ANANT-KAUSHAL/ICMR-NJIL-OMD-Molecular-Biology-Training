## Objective
Understand the principle and workflow of Real-Time PCR 
(RT-PCR) using SYBR Green detection chemistry before 
running the first sample.

## Key Concept — What is RT-PCR?
Real-Time PCR quantifies DNA/cDNA amplification as it 
happens — cycle by cycle — using a fluorescent dye 
(SYBR Green) rather than visualising bands on a gel 
after the fact.

## Master Mix Used
**Applied Biosystems PowerUp SYBR Green Master Mix**  
A 2X pre-formulated mix containing almost all reagents.  
You only add: Forward Primer (FP), Reverse Primer (RP), 
cDNA template, and Nuclease-Free Water (NFW).

## General Protocol Steps Learned
1. Prepare reaction mix (Master Mix) first
2. Prepare base with primers, then add cDNA samples last
3. Place PCR tubes on tray on ice block at ~20°C, 
   in calculated order
4. Centrifuge all PCR tubes containing Master Mix + 
   SYBR Green briefly before running

## Precautions Noted
1. **Dye sensitivity:** For DYE-based detection, ALWAYS 
   use **white-coloured PCR tubes** to prevent light 
   passing through — dyes are light sensitive
2. **No transparent tubes.** If no white tubes available, 
   wrap in **foil**
